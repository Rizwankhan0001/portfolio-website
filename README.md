## ✨ Features

- **Modern Design**: Vibrant gradient color scheme with glass morphism effects
- **Smooth Animations**: CSS animations and transitions throughout
- **Responsive Layout**: Optimized for all devices and screen sizes
- **Interactive Elements**: Hover effects, floating animations, and dynamic content
- **Performance Optimized**: Fast loading with efficient code structure

```
MY PORTFOLIO/
```

## 🚀 Quick Start

### Frontend (Static Version)
```bash
cd frontend
# Open index.html in your browser
```

### Backend Server
```bash
cd backend
npm install
npm start
```

### Full Stack Setup
```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio-website.git
cd portfolio-website

# Install backend dependencies
cd backend
npm install

# Start the server
npm start
```

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup and structure
- **CSS3**: Advanced styling with gradients, animations, and flexbox/grid
- **JavaScript**: Interactive functionality and DOM manipulation
- **Font Awesome**: Icon library for visual elements

### Backend
- **Node.js**: Runtime environment
- **Express.js**: Web application framework
- **MongoDB**: Database for dynamic content
- **CORS**: Cross-origin resource sharing

### Design Features
- **Gradient Backgrounds**: Beautiful color transitions
- **Glass Morphism**: Frosted glass effects
- **Floating Animations**: Smooth element movements
- **Responsive Grid**: Flexible layout system
- **Interactive Cards**: Hover effects and transformations
